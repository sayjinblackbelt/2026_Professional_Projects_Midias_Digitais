## 🎯 Sobre este repositorio

Este repositorio documenta proyectos, actividades, materiales y experimentaciones **reales y en desarrollo** relacionados con la actuación profesional en educación, medios digitales, diseño y tecnología.

El enfoque está en el proceso completo:

**Planificación → Ejecución → Retroalimentación → Revisión → Resultados → Documentación**

## 🧩 Áreas principales

- 🎨 Diseño gráfico y comunicación visual
- 📱 Medios digitales
- 🤖 Inteligencia Artificial aplicada
- 💻 Tecnología educativa
- 🎓 Producción de materiales para la enseñanza
- 🌐 Cultura y ciudadanía digital
- 🧠 Creatividad, comunicación y pensamiento crítico
- 💼 Preparación para el mundo del trabajo

## 📚 Organización pedagógica

Los proyectos combinan práctica, Aprendizaje Basado en Proyectos, sprints educativos, retroalimentación, revisión y producción de portafolios.

El recorrido está orientado por:

**Observar → Reflexionar → Tomar iniciativa → Actuar → Saber esperar**

## 📊 Evaluación

La evaluación es formativa y considera proceso, producción, revisión, colaboración, responsabilidad digital y evolución. Se utilizan diagnóstico, listas de verificación, observación, retroalimentación entre pares, autoevaluación y portafolio.

## 🔐 Privacidad y publicación responsable

Este repositorio es público. No deben publicarse datos personales, contactos, evaluaciones individuales, fotografías identificables, credenciales o documentos sensibles sin autorización adecuada.

Cuando sea necesario, se utilizan datos agregados, ejemplos ficticios, anonimización y materiales autorizados.
