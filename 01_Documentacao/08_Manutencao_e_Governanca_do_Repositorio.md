# Manutenção e Governança do Repositório

## Finalidade

Este repositório registra planejamento, materiais e produtos pedagógicos da Oficina de Mídias Digitais. É uma memória institucional e uma base de reutilização para o educador.

## Estrutura

- `01_Documentacao/`: identidade, metodologia, objetivos, registros e governança.
- `02_Planejamento/`: calendário, módulos, competências e ajustes de percurso.
- `03_Sprints/`: planos, roteiros, atividades e registros de cada projeto.
- `04_Materiais_Educador/`: guias de condução, checklists e roteiros.
- `05_Materiais_Educandos/`: fichas, textos de apoio e orientações.
- `docs/`: sínteses rápidas e documentação de apoio.

## Convenções

- Usar nomes com prefixo numérico quando a ordem for importante.
- Preferir arquivos Markdown (`.md`) para documentos editáveis.
- Nomear materiais datados no formato `AAAA-MM-DD_tema.md`.
- Atualizar o índice ou README da pasta quando criar conteúdo relevante.
- Registrar mudanças de planejamento com data e motivo.

## Privacidade e segurança

O repositório é público. Não publicar nomes completos de educandos, contatos, avaliações individuais, fotos identificáveis, dados de saúde, documentos pessoais, credenciais ou respostas associadas a uma pessoa.

Usar exemplos fictícios, dados agregados e arquivos anonimizados. Materiais com dados pessoais devem permanecer em ambiente institucional com acesso restrito.

## Rotina de manutenção

**Após cada aula:** atualizar o registro de execução e anexar somente materiais seguros para publicação.  
**Ao final de cada módulo:** revisar cronograma, incluir produtos-modelo e registrar aprendizagens.  
**Ao final do semestre:** consolidar relatório, arquivar versões finais e atualizar este README.

## Controle de qualidade antes de publicar

- conferir clareza, ortografia e links;
- verificar se não há dados pessoais;
- confirmar direitos de uso de imagens, textos e mídias;
- confirmar que o arquivo está no diretório correto;
- atualizar referências cruzadas quando necessário.
