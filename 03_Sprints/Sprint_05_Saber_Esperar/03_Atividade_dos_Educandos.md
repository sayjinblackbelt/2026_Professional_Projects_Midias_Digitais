# 11. Revisão Final

### Imagem

- [ ] As imagens estão adequadas.
- [ ] Os enquadramentos estão bons.
- [ ] Os textos podem ser lidos.
- [ ] A sequência faz sentido.

### Áudio

- [ ] As falas podem ser entendidas.
- [ ] O volume está equilibrado.
- [ ] A música não cobre as falas.
- [ ] Não há ruídos que prejudiquem o entendimento.

### História

- [ ] O começo apresenta o contexto.
- [ ] O desenvolvimento mostra a atividade.
- [ ] O final encerra a ideia.
- [ ] A produção cumpre seu objetivo.

### Ética

- [ ] As pessoas são representadas com respeito.
- [ ] Não há exposição desnecessária.
- [ ] Não há informações pessoais indevidas.
- [ ] Os cuidados institucionais foram respeitados.
