# Política de Privacidade — Repositório Público

Este repositório é público e deve conter somente documentação adequada à divulgação.

## Não publicar
- nomes completos de educandos;
- contatos, documentos ou endereços;
- notas ou avaliações individualizadas;
- observações pessoais sensíveis;
- fotografias ou vídeos identificáveis sem autorização apropriada;
- senhas, tokens, chaves ou credenciais;
- dados internos que não tenham finalidade pública.

## Identificação
Quando necessário para documentação pública, utilizar IDs anônimos ou dados agregados.

## Portfólio
Projetos e links públicos devem ser revisados antes da publicação para verificar dados pessoais, créditos, permissões e conteúdo incorporado.

## Regra de modelos
Quando uma etapa não possuir arquivo de referência ou modelo adequado, criar um modelo mínimo reutilizável, sem inventar conteúdo real.

## Auditoria
Toda alteração relevante deve ser seguida por teste do GitHub Pages. Uma etapa só deve ser considerada concluída após a validação da publicação e dos registros relevantes.
