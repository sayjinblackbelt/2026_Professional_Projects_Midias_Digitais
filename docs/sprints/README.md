# Modelos e registros de Sprints

Esta pasta reúne os registros públicos dos Sprints do projeto.

Quando um Sprint ainda não possuir registro real, utilizar `templates/MODELO_SPRINT.md` como referência. Não criar resultados fictícios.

## Estrutura recomendada
- identificação e período;
- objetivo;
- preparação;
- atividades;
- evidência/produto;
- registro da execução;
- reflexão;
- critério de avanço;
- revisão de privacidade.

Registros individualizados ou dados pessoais devem permanecer fora deste repositório público.
