# Materiais do Educador

Espaço destinado a:
- roteiros de aula;
- materiais de apoio;
- prompts pedagógicos;
- critérios de avaliação;
- orientações de condução;
- modelos de atividades.

## Padrão recomendado
Cada material deve conter título, objetivo, contexto, desenvolvimento, atividade prática, critérios de acompanhamento e reflexão final.
